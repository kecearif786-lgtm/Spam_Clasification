PENAMBAHAN FITUR UPLOAD SCREENSHOT PADA STREAMLIT CLOUD

1. Backup app.py lama.
2. Ganti app.py di repository GitHub dengan app.py dari paket ini.
3. Perbarui requirements.txt dengan file dari paket ini.
4. Tambahkan packages.txt ke folder utama repository (sejajar dengan app.py).
5. Pastikan spam_model.pkl dan tfidf_vectorizer.pkl tetap ada di folder utama.
6. Commit/push perubahan ke GitHub. Streamlit Cloud akan melakukan deployment ulang.
7. Tunggu deployment selesai, lalu buka kembali website.

Catatan:
- OCR memakai Tesseract bahasa Indonesia dan Inggris (ind+eng).
- packages.txt memasang Tesseract di server Streamlit Cloud.
- Kode mempertahankan aturan dari app.py awal: prediction == 1 berarti SPAM.
- Uji dengan screenshot yang tulisannya jelas. Periksa dan koreksi hasil OCR sebelum menekan tombol deteksi.
- Jika model sebenarnya memakai label selain 1 untuk SPAM, aturan label di app.py perlu disesuaikan.
